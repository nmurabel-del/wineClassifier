# WineClassifier

Projet de classification du vin.

## Structure

- `api/` : API du projet.
- `frontend/` : interface utilisateur.
- `training/` : entraînement du modèle.
- `models/` : stockage des modèles entraînés.

## Installation

```bash
python -m venv .venv
```

Activez l’environnement virtuel, puis installez les dépendances :

```bash
pip install -r requirements.txt
```
